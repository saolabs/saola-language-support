# Saola Language Support v1.0.0

VS Code language support for .sao files: highlighting, snippets, formatting, completion and TypeScript-aware script/template diagnostics.

## Compatibility

VS Code ^1.75.0; bundled TypeScript runtime libraries in the VSIX.

## Validation

Audit, all eight test scripts, TypeScript build and VSIX packaging passed.

## Release scope

Coordinated v1.0.0 source release of the Saola ecosystem on GitHub. Registry publishing (npm, Packagist or VS Code Marketplace) is a separate step. Existing tags and previously published registry versions are unchanged.
